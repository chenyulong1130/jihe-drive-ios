# 2026-11-20

## MainTabView 底部导航改为可滑动分页

文件：`JiheDrive/App/MainTabView.swift`

- 页面容器由「ZStack 叠放 + opacity/scale 交叉淡入」改为 `HStack` 三页并排 + `offset(-index * w + dragOffset)`，外层 `frame(width: w)` + `clipped()` 做视口裁切。
- 新增 `DragGesture(minimumDistance: 8)` 以 `simultaneousGesture` 挂在容器上：只在水平意图（`|dx| > |dy| * 1.2`）时生效，纵向滚动仍交给页面内 ScrollView；首尾页外拖乘 0.3 阻尼；松手用 `predictedEndTranslation` 判定翻页（阈值 0.22w），`dragOffset = 0` 与 `tab` 变更放在同一个 `withAnimation(Motion.liqid)` 事务内避免两段动画。
- 非当前页按进度做 0.3 透明度 + 0.04 缩放纵深，`allowsHitTesting(progress < 0.5)`。
- `LiquidTabBar`：`HStack(spacing: 0)` + 每个按钮 `.frame(maxWidth: .infinity)`，点击区从「图标周围一小块」扩到整条宽度的 1/3（左右边距 36 → 16）；蓝色胶囊仍按内容宽度绘制（背景在扩展 frame 之前应用），matchedGeometryEffect 保留。
- 加了 `.sensoryFeedback(.selection, trigger: tab)`。

注意：iPhone only、iOS 17，交互式 3D（Vehicle3DSheet）在弹窗里，HeroStage 的 SCNView 是 interactive: false，车辆页地图也 allowsHitTesting(false)，所以水平拖拽不会和这些控件抢手势。
